# thcxmodel-for-input-current-analysis

This repository contains the simulation, analysis, and plotting code used to study the effects of biological and BNC input currents in the thalamocortical network model.

## Workflow

The complete analysis should be run in the following order:

1. Run the network simulations in `Simulations`.
2. Run the PSD and theta-gamma coupling analyses in `psd_coupling_analysis`.
3. Run the performance analysis in `perf_analysis`.

The outputs required for the manuscript figures have already been collected in `plot_for_figures`. Therefore, if the goal is only to reproduce the manuscript figures, the notebooks in `plot_for_figures` can be run directly without rerunning the simulations or upstream analyses.

> **Important:** Outside `plot_for_figures`, the Python analysis code depends on output generated by `Simulations`. Run the simulations first before executing code in `psd_coupling_analysis` or `perf_analysis`.

## Repository structure

```text
thcxmodel-for-input-current-analysis/
|-- Simulations/                 # Network simulation code and input waveforms
|-- psd_coupling_analysis/       # PSD and theta-gamma coupling analyses
|-- perf_analysis/               # Performance analysis
`-- plot_for_figures/            # Standalone notebooks and prepared figure data
```

## 1. Run the simulations

Simulation templates and input waveforms are located in `Simulations`. The Bio and BNC conditions are represented by the `bio` and `hard` directory names, respectively.

From the repository root:

```bash
cd Simulations/rand3
```

First create the ten simulation directories for each condition:

```bash
bash copy_sweep_bio
bash copy_sweep_hard
```

Then run the simulations:

```bash
bash run_sweep_bio
bash run_sweep_hard
```

The simulation code is compiled with the supplied `Makefile` and requires a C++ compiler with OpenMP support. Each simulation writes its results into an `out` directory. These output files are the inputs to the analysis steps below.

## 2. Run the PSD and coupling analyses

After all required simulations have finished, open the notebooks in `psd_coupling_analysis`:

```text
psd_coupling_analysis/
|-- calculate_psd.ipynb
`-- calculate_theta_gamma_coupling.ipynb
```

Run the notebooks from top to bottom. Before running them, verify that the simulation paths in the notebooks point to the output directories created in Step 1.

## 3. Run the performance analysis

After the simulations have finished, enter `perf_analysis`:

```bash
cd perf_analysis
```

Check the configuration near the top of `Main_perf.py`, especially `ROOT`, `CONDITION`, and `FILENAMES`. Then run:

```bash
python Main_perf.py
```

Run the analysis separately for the Bio and BNC conditions by setting `CONDITION = "bio"` or `CONDITION = "hard"`. The script saves the calculated performance results as an NPZ file in the configured simulation root.

## Reproduce the manuscript figures

To reproduce only the manuscript figures, use `plot_for_figures`. This is the only self-contained part of the repository: its `data` directory contains the prepared results needed by the plotting notebooks.
The large `time_cx` example datasets are stored as gzip-compressed text files, and the raster plotting notebook reads the `.gz` files directly with NumPy; no manual extraction is required.

```bash
cd plot_for_figures
jupyter lab
```

Run the relevant notebook from top to bottom:

```text
Performance-comparison-HARD.ipynb
comparison-single_psd.ipynb
plot_forfigures-raster.ipynb
theta_gamma_coupling_plot.ipynb
```

Generated figures are saved in `plot_for_figures/figures`.

## Python dependencies

The analysis and plotting code uses common scientific Python packages, including NumPy, SciPy, Matplotlib, and JupyterLab or Jupyter Notebook. Some notebooks may use additional packages imported in their first code cell. Install any missing dependencies in the active Python environment before running the notebooks.
